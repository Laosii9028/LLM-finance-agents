# Discord `/早報` 觸發設定

## 1. 建立 Discord App

1. 到 Discord Developer Portal 建立 Application。
2. 在 General Information 複製 Application ID 與 Public Key。
3. 到 Bot 頁建立／重設 Bot Token。Token 只用於本機註冊指令，不可上傳 GitHub。
4. 到 Installation/OAuth2，把 App 安裝到自己的 Discord 伺服器。
5. 開啟 Discord 開發者模式，複製自己的 User ID 與伺服器 Guild ID。

## 2. 建立 GitHub fine-grained token

1. GitHub Settings → Developer settings → Personal access tokens → Fine-grained tokens。
2. Repository access 只選 `Laosii9028/LLM-finance-agents`。
3. Repository permissions 只開 `Actions: Read and write`。
4. 建立後複製 token，不可放進 repo。

## 3. 部署 Cloudflare Worker

在本資料夾執行：

```powershell
npm install
npx wrangler login
npx wrangler secret put DISCORD_PUBLIC_KEY
npx wrangler secret put GITHUB_TOKEN
npx wrangler secret put ALLOWED_DISCORD_USER_IDS
npx wrangler secret put ALLOWED_DISCORD_GUILD_ID
npm run deploy
```

- `DISCORD_PUBLIC_KEY`：Discord Application Public Key。
- `GITHUB_TOKEN`：上一步建立的 fine-grained token。
- `ALLOWED_DISCORD_USER_IDS`：你的 Discord User ID；多人可用逗號分隔。
- `ALLOWED_DISCORD_GUILD_ID`：你的 Discord 伺服器 ID。

部署後會取得類似 `https://llm-finance-discord-trigger.<帳號>.workers.dev` 的網址。

## 4. 設定 Interactions Endpoint

把 Worker 網址貼到 Discord Developer Portal → General Information → Interactions Endpoint URL。
Discord 會傳送 PING 並驗證簽章，成功後才能儲存。

## 5. 註冊 `/早報`

只在本機 PowerShell 暫時設定以下環境變數，不要寫進檔案：

```powershell
$env:DISCORD_APPLICATION_ID="你的Application ID"
$env:DISCORD_BOT_TOKEN="你的Bot Token"
$env:DISCORD_GUILD_ID="你的伺服器ID"
npm run register
```

完成後清除本機 token：

```powershell
Remove-Item Env:DISCORD_BOT_TOKEN
```

回到 Discord 輸入 `/早報`，看到「已觸發早報」後，GitHub Actions 會重新執行，完成時由原本的 Discord webhook 傳送報告。

## 安全注意

- GitHub token、Bot token 不得寫入 GitHub、程式碼或 `wrangler.jsonc`。
- Worker 只允許白名單 User ID 與指定 Guild ID 觸發。
- 如果 token 外洩，立即到 GitHub／Discord 撤銷並重建。
